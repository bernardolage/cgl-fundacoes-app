# CGL Fundações — Sistema de Gestão (front-end publicado)

Front-end estático do sistema interno da CGL Fundações, publicado via GitHub Pages.
Os dados ficam no Supabase, atrás de login, MFA e RLS — este repositório contém
apenas HTML/CSS/JS públicos (a única chave presente é a *publishable*, pública por design).

O código-fonte completo (migrations, edge functions, documentação) vive em
repositório privado. Este repo recebe apenas o pacote de publicação.
